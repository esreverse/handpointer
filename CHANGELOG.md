# Changelog

What changed in each version of TinyPointer. The section for a version is shown in the update dialog,
so write it for people using the app.



## 1.1.0

First release of TinyPointer, based on TinyHand 1.0.2 by Kamran Ahmed.

- Rainbow ink: Lines run through every colour, with adjustable speed and a hue shift for each new line
- Stroke size and line opacity can be set separately from the pointer size
- Tap circle: A circle grows and fades out where you tap
- Tap sound plays on tap only, or on tap and draw
- Zoom loupe: Hold a key to magnify the screen around the pointer
- Ink colours sit right in the toolbar
- The toolbar can be moved with the handle on its left; right-click the handle to put it back
- The toolbar can be shown or hidden, and gets out of the way while you interact with your Mac
- New shortcuts for clearing, colours, switching pointers, sound and the toolbar; single keys work while the pointer is on
- Optional: Right-click turns the pointer off
- Settings reorganised into General, Shortcuts, Draw, Zoom, Pointers, Sound and About
- Updates are checked and installed automatically
